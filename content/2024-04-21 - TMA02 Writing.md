# Anonymisation rule
```json
{  
  "Rules": [
    {
      "Regex": "(luke(\\.| )?foreman)|(\\bLuke)|(\\bLF\\b)",
      "Replacement": "Lucy"
    },
  ]
}
```

`luke(\\.| )?foreman` expands to:
1) Luke.Foreman - email addresses
2) Luke Foreman - Full name
3) LukeForeman - Ticketing user names

`(\\bLuke)` means Luke where it starts on a word boundary. This is to try and prevent false replacements like where the name to replace is `Ash` and the text contains `dashboard`.

`(\\bLF\\b)` match exactly LF and it must have a word boundary on either side, commonly in the text we use initials when referring to
